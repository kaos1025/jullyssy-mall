> 대상: 운영자(어드민 사용자) / 작성 근거: PR #97 (홈 ISR + 배너·이벤트 캐시 격리) 머지
> 관련 화면: 어드민 → `배너`(탑배너), `히어로 배너`, `이벤트 카테고리`

---

## 1. 화면 반영 시간 (중요)

배너·이벤트의 **예약 시작/종료 시각은 설정 시각으로부터 최대 10분 후에 실제 화면에 반영**됩니다.
분 단위로 정확한 노출이 필요한 경우(타임세일 등) 개발자에게 문의하세요.

| 작업 | 화면 반영 |
|---|---|
| 배너/이벤트 **등록·수정·삭제**(저장 버튼) | 저장 직후 반영 (캐시 즉시 무효화) |
| 미리 설정해 둔 **예약 시작 시각 도래** | 최대 10분 지연 |
| 미리 설정해 둔 **예약 종료 시각 도래** | 최대 10분 지연 |

- 이유: 홈/쇼핑 화면은 서버 부하·비용 절감을 위해 5분 단위 캐시(페이지 5분 + 데이터 5분)로 제공됩니다. 저장 버튼을 누르는 작업은 캐시를 즉시 비우지만, 시각 도래는 캐시가 자연 만료될 때 반영됩니다.
- 대상: 탑배너, 히어로 배너, 이벤트 카테고리(GNB 이벤트 탭) 모두 동일.

## 2. 확인 방법

- 저장 후 홈(`/`)을 새로고침해 반영을 확인합니다(브라우저 캐시가 의심되면 시크릿 창).
- 예약 배너는 시작 시각 + 10분까지 기다린 뒤 확인합니다. 그래도 보이지 않으면 `노출 기간`·`활성` 체크 상태를 먼저 확인한 뒤 개발자에게 문의하세요.

## 3. 상품 등록/수정 반영

- 상품 등록·수정·품절 변경은 저장 직후 홈/목록에 반영됩니다(캐시 즉시 무효화). 늦어도 5분 이내에는 반영됩니다.
