# 쥴리씨 (Jullyssy) — 브랜드 & 디자인 가이드

> Claude Design 온보딩용 브랜드 프로필

## 1. 브랜드 정체성

### 한 줄 정의
20~40대 여성을 위한 데일리 캐주얼 여성의류 자사몰.

### 풀 정의
쥴리씨(Jullyssy)는 네이버 스마트스토어에서 시작해 자사몰로 확장한 여성의류 브랜드입니다.
트렌디하면서도 부담 없이 일상에서 입을 수 있는 옷을 제안하며, 화면 너머의 고객과 "따뜻한 쇼핑메이트"로 관계를 맺는 것을 목표로 합니다.

### 타겟
- 주 타겟: 20대 후반 ~ 40대 초반 여성
- 라이프스타일: 오피스룩 / 데일리룩 / 데이트룩 / 하객룩 수요
- 구매 행동: 모바일 중심, 인스타그램·블로그에서 영감을 얻고 구매는 쇼핑몰에서 완료

### 브랜드 슬로건 / 톤 메시지
- "화면 너머의 여러분에게 따뜻한 쇼핑메이트"

## 3. 컬러 시스템

### Primary
- **Primary (Orange)**: 브랜드 강조 컬러
  - 사용처: CTA 버튼, 가격 할인 표시, 활성 상태, 링크 호버
  - 따뜻하고 활기찬 톤 — 여성의류 쇼핑몰의 감성과 어울리는 오렌지 계열
  - ⚠️ 절제해서 사용 — 화면당 포인트 1~2곳

### Neutral (메인 톤)
- **White**: 기본 배경
- **Gray 50**: 섹션 구분 배경 (예: Footer, 카드 배경)
- **Gray 100**: 비활성 탭, Pill 버튼 기본 상태
- **Gray 400**: 비활성 아이콘, 보조 텍스트
- **Gray 700**: 본문 텍스트
- **Black / Gray 900**: 제목, 강조

### Semantic
- **Success (Green)**: 결제 완료, 배송 완료
- **Warning (Amber)**: 품절 임박, 마감 임박
- **Error (Red)**: 에러, 품절, 삭제
- **Info (Blue)**: 공지, 배송 정보

### 원칙
- 화면당 컬러 3가지 이하 (화이트 + 그레이 스케일 + 포인트 1)
- 할인율 같은 숫자는 Primary(오렌지)로 강조, 남발 금지
- 품절은 검정 반투명 오버레이 + "SOLD OUT" 텍스트

## 4. 타이포그래피

### 서체
- **본문/UI**: **Pretendard** (한국어 최적화)
- **영문/숫자**: Pretendard가 라틴 문자도 커버 → 별도 영문 폰트 불필요

### 스케일
| 용도 | 크기 | 굵기 |
|---|---|---|
| 페이지 제목 (H1) | 24~28px | Bold (700) |
| 섹션 제목 (H2) | 18~20px | Bold (700) |
| 카드/소섹션 제목 (H3) | 16px | SemiBold (600) |
| 본문 | 14~15px | Regular (400) |
| 상품명 | 13~14px | Regular (400) |
| 가격 (정가) | 14~15px | Medium (500) |
| 가격 (할인가) | 16px | Bold (700) |
| 할인율 | 14px | Bold (700) · Primary |
| 보조 텍스트 (메타) | 12px | Regular · Gray 500 |
| 아주 작은 라벨 (탭바) | 10px | Medium |

### 원칙
- 한 화면에 폰트 웨이트 3종류 이하 (Regular / Medium / Bold)
- 줄간격(line-height): 본문 1.5, 제목 1.3
- 한국어 본문은 자간 -0.01em (살짝 좁혀서 가독성 ↑)

## 5. 레이아웃 & 간격

### 그리드
- **모바일 (기본)**: 1열 또는 2열 (상품 그리드)
- **태블릿 (md, 768px+)**: 콘텐츠 가로폭 fluid
- **PC (lg, 1024px+)**: max-width 1280px 컨테이너, 중앙 정렬, 4열 상품 그리드

### 간격 스케일 (Tailwind 기반)
- 아주 작음: 4px (gap-1)
- 작음: 8px (gap-2)
- 기본: 16px (gap-4)
- 섹션 내: 24px (gap-6)
- 섹션 간: 48px (py-12)
- 페이지 블록 간: 64~80px (py-16 / py-20)

### 원칙
- 여백은 아낌없이
- 섹션 경계는 보더보다 **여백 + 배경색 변화**로 구분
- 카드/버튼 내부 패딩은 16px 기본, 모바일에서는 12px까지 타이트하게 허용

## 6. 컴포넌트 스타일

### 공통
- **기반 라이브러리**: shadcn/ui + Tailwind CSS
- **보더 라디우스**: 8px (rounded-lg) 기본, 이미지 카드도 동일
- **그림자**: 거의 사용 안 함. 쓰더라도 shadow-sm (subtle)
- **보더**: 1px solid, gray 100~200 (존재감 최소화)

### 버튼
- **Primary**: bg-primary, text-white, rounded-lg, py-3 px-6, 호버 시 살짝 어둡게
- **Outline**: border gray 200, 호버 시 gray 100 배경
- **Ghost**: 배경 없음, 텍스트만 (메뉴, 보조 액션용)
- **Size**: sm(36px) / md(40px, 기본) / lg(48px, CTA)

### 상품 카드 (ProductCard) — ⭐ 핵심
- **이미지 비율**: 3:4 세로형 (의류 쇼핑몰 표준), `aspect-[3/4]`
- **이미지 처리**: object-cover, rounded-lg, hover 시 scale-105
- **상품명**: 1줄 말줄임(line-clamp-1), 14px
- **가격 영역** (할인 유무로 분기):
  - 할인 없음: 정가만, Medium 500
  - 할인 있음: 원가(line-through, text-xs text-muted) + 할인가(Bold) + 할인율(Primary)
- **뱃지**: 좌상단 "NEW"(검정 배경) / "SOLD OUT" 중앙 오버레이
- **카드 높이**: 리뷰 있/없 관계없이 **일정하게 유지** (min-h 설정)

### 카테고리 칩 / Pill 버튼
- **형태**: rounded-full, 가로 스크롤 (모바일)
- **기본**: bg-gray-100 text-gray-700
- **활성**: bg-primary text-white
- ❌ 원형 아이콘 금지

### 헤더
- **높이**: 56px
- **배경**: white/80 backdrop-blur, sticky top-0
- **구분선**: 보더 아닌 shadow-sm
- **로고**: 텍스트 "쥴리씨", Bold, Primary 컬러

### 푸터
- **배경**: bg-gray-50
- **사업자 정보**: 12px 보조 텍스트
- **모바일에서 하단 네비(60px)와 겹치지 않게 pb-24**

### 탭바 (모바일 하단)
- **높이**: 60px + safe-area-inset-bottom
- **아이콘**: lucide-react, size 22, strokeWidth 1.5
- **라벨**: 10px Medium, 아이콘 아래
- **활성**: Primary / 비활성: Gray 400
- **구성**: 홈 / 카테고리 / 찜 / 마이페이지 / 장바구니

## 7. 아이콘 & 이미지

### 아이콘
- **라이브러리**: lucide-react (고정)
- **기본 굵기**: strokeWidth 1.5 (얇고 모던)
- **기본 크기**: 24px (UI), 22px (탭바)

### 이미지
- **상품 이미지**: 3:4 세로형 (740×987 또는 비율만 맞추면 OK)
- **히어로 배너**: 모바일 40vh, PC 400px 높이
- **OG 이미지**: 1200×630

### 이미지 처리 원칙
- 배경은 가급적 화이트 or 파스텔 톤
- 모델 컷 > 제품 단독 컷 (의류 특성)
- 원색·과채도 보정 지양, 자연광 느낌

## 8. 보이스 & 카피 톤

### 톤 원칙
- **친근하지만 과하지 않게** — 존댓말 기본, 이모티콘 남발 금지
- **담백하게** — 과장된 세일즈 카피 지양 ("대박!", "역대급!" ❌)
- **실용적으로** — 기능/혜택을 명확하게

### 예시
- ✅ "오늘 주문 시 내일 도착"
- ✅ "무료배송 (5만원 이상)"
- ✅ "봄 신상 입고"
- ❌ "🔥 초특가 세일!!! 🔥"
- ❌ "지금 아니면 못 사요!!"

### CTA 문구
- 장바구니: "장바구니 담기"
- 결제: "바로구매" / "결제하기"
- 회원: "로그인" / "회원가입"
- 쿠폰: "쿠폰 적용"

### 에러 메시지
- 짧고 명확하게, 사용자를 탓하지 않는 톤
- ✅ "주문을 완료하지 못했어요. 다시 시도해주세요."
- ❌ "오류가 발생했습니다."

## 9. 모바일 퍼스트 규칙

### 필수 원칙
- **모든 화면은 375px(iPhone SE 기준)부터 설계 시작**
- 하단 고정 영역은 `env(safe-area-inset-bottom)` 처리
- 터치 타겟 최소 44×44px
- 가로 스크롤 영역은 `scrollbar-hide` + 스와이프 지원

### 히어로 배너
- **모바일 높이: 40vh** (60vh 절대 금지 — 첫 스크롤 없이 하단 상품 살짝 보이게)

### 네비게이션
- 모바일: 햄버거 → Sheet 사이드바 (카테고리 아코디언)
- 하단 탭바 항상 표시 (단, 결제 페이지 등 풀스크린 시 숨김)

## 10. 기술 스택 (참조용)

디자인 산출물이 실제 구현되는 환경:

- **프레임워크**: Next.js 14 (App Router)
- **스타일**: Tailwind CSS + shadcn/ui
- **폰트**: Pretendard (웹폰트 로드)
- **아이콘**: lucide-react
- **이미지**: next/image
- **애니메이션**: Tailwind transition 기본, 필요시 Framer Motion

→ 산출물이 이 스택으로 구현 가능해야 함. 커스텀 CSS 최소화, Tailwind 유틸리티 클래스로 표현 가능해야 함.
